# paper-notes Header Card 设计规范

> **生效日期**：2026-06-16
> **适用场景**：微信公众号等移动端长文顶部 Banner
> **迭代版本**：v2.0（9:16 竖版重构）

---

## 🎯 核心设计原则

### 「Header Card 只是身份 Banner，不是全文摘要」

1. **用户在微信里扫一眼就知道：这是哪篇论文？打了多少分？**
2. **元数据（作者、机构、链接）是正文的事，不要在卡片里重复占位**
3. **所有元素必须考虑窄屏显示，禁止横向挤压和文字截断**

---

## 📐 最终设计参数

### 基础配置

| 项 | 值 | 说明 |
|----|---|------|
| **画布尺寸** | 600 × 585 px | 类 9:16 竖版，高度刚好容纳核心内容 |
| **背景色** | `#0B1430` | 深蓝渐变同整套视觉 |
| **文件体积目标** | < 70K | 保证加载速度 |

### 元素布局（从上到下）

```
┌─────────────────────────────────┐  ← PADDING = 50px
│            [LOGO]               │  ← 居中，最大宽度 80px
│                                 │
│  科学仪器 Agent 基准：LabOSBench   │  ← 一行标题，字号 26px 加粗
│                                 │
├─────────────────────────────────┤  ← 分割线 2px #4CC3FF
│                                 │
│  重要性       1.8/2  创新性   1.8/2  │  ← 两列布局
│  可验证性     1.8/2  产业可用 1.7/2  │  左列 3 项，右列 2 项
│  可复用性     1.7/2                 │  标签 16px 常规，分数 16px 加粗
│                                 │
├─────────────────────────────────┤  ← 分割线 2px #4CC3FF
│                                 │
│          8.8 / 10               │  ← 总分居中放大，70px 加粗
│                                 │  ← 留 10px 间距到底部条
■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■  ← 底部条 3px #4CC3FF
└─────────────────────────────────┘
```

### 字体配置

| 元素 | 字体 | 字号 | 颜色 |
|------|------|------|------|
| 标题 | SourceHanSansCN Bold | 26px | `#4CC3FF` |
| 维度标签 | SourceHanSansCN Regular | 16px | `#FFFFFF` |
| 维度分数 | SourceHanSansCN Bold | 16px | `#4CC3FF` |
| 总分 | SourceHanSansCN Bold | 70px | `#4CC3FF` |

### 布局约束

- **两列间距**：≥ 40px
- **标签与分数间距**：≥ 40px（安全距离，防止重叠）
- **标签超长处理**：自动截断英文，只显示中文部分（如「产业可用性」）
- **总分到底部条间距**：≥ 10px（禁止文字与线条重叠）

## 📝 迭代历史

### v2.0（2026-06-16，当前版本）

**背景**：v1.0 16:9 横版在手机窄屏下出现各种横向挤压、文字重叠、空白浪费

**改动**：
- ✅ 画布比例从 16:9 改为 9:16 竖版（手机原生适配）
- ✅ 评分区从单列改为两列（左3右2），紧凑不浪费空间
- ✅ 移除元数据区域（作者、机构、链接）—— 正文顶部已有，不重复占位
- ✅ 英文长标题改为一行「中文标题 + 缩写」
- ✅ 总分居中放大，底部条紧贴无空白
- ✅ 标签超长自动截断英文部分
- ✅ 文件体积从 228K → 57K（减小 75%）

### v1.0（2026-06 之前）

- 16:9 横版双图（score_card + info_card）
- 单独 info_card 放完整元数据
- 高度大，空白多

## ⚠️ 注意事项

1. **不要轻易加内容到 Header Card**
   - 新内容先问：这是「用户扫一眼就必须知道的身份信息」吗？
   - 如果不是，放正文去。

2. **不要改画布宽度 600px**
   - 600px 是经过验证的：微信编辑器不会压缩，手机显示适中
   - 更宽会导致手机端显示太小，更窄会模糊

3. **测试标准**
   - 生成后必须在真实手机微信里查看效果
   - 检查：没有文字重叠、没有截断、没有大片空白
